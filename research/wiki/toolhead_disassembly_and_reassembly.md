# Overview

## Structural description

 The toolhead can be broadly divided into 5 functional parts: cover, male mount, extruder unit, hotend, control board.

Disassembly and reassembly must be performed in the specified order.

Please read the steps below in full before attempting any operations.

## Difficulty and Time Estimate

 Difficulty ： ★★★ ☆☆ (moderate)

 Estimated Time ：40mins

## Tools and Parts Required

 H2.0 hex key

 H1.5 hex key

# Toolhead disassembly

 Use an H2.0 hex key to unscrew the three screws and remove the top cover & the rear cover

## Step 5. Disassemble the extruder unit

 Use H1.5 & H2.0 hex key to unscrew the 4 fixing screws and remove the extruder unit.

[img https://wiki.snapmaker.com/u1/移除挤出单元螺丝.jpg]

 Use an H2.0 hex key to unscrew the 4 fixing screws and remove the extruder bearing holder

[img https://wiki.snapmaker.com/u1/u1_extruder-unit_extruder-bearing-housing.jpg]

 Use an H2.0 hex key to unscrew the spring fixing screw and remove the compression spring—1 and the spring block—2

[img https://wiki.snapmaker.com/u1/u1_extruder-unit_compression-spring-screw.jpg]

[img https://wiki.snapmaker.com/u1/u1_extruder-unit_remove-compression-spring-and-pressure-block.jpg]

 Use an H1.5 hex key to unscrew the 2 fixing screws and sequentially remove the filament runout sensor—2, the driven extruder assembly—3, and the driving extruder assembly—4

[img https://wiki.snapmaker.com/u1/u1_extruder-unit_disassembly1.jpg]

 Use an H2.0 hex key to unscrew the 2 fixing screws and remove the extruder motor—1 and the motor heat shield—2

# Toolhead assembly

## Step 1. Assemble the extruder unit

 Install the motor heat shield and the extruder motor in the orientation shown（ Ensure that the position of the extruder motor cable matches the illustration ）, and use an H2.0 hex key to tighten the 2 fixing screws

[img https://wiki.snapmaker.com/u1/u1_extruder-motor_install.jpg]

[img https://wiki.snapmaker.com/u1/u1_extruder-motor_screws2.jpg]

 Install the driving extruder assembly and the driven extruder assembly sequentially, ensuring that the 3 gears shown mesh correctly. Rotate the active extruder gear to confirm that the other two gears turn smoothly, indicating proper installation

[img https://wiki.snapmaker.com/u1/u1_extruder-unit_assemble1.jpg]

 Install the filament runout sensor and use an H1.5 hex key to tighten the 2 fixing screws

[img https://wiki.snapmaker.com/u1/u1_extruder-unit_assemble2.jpg]

 Install the compression spring and spring block, placing the spring block above the compression spring, and use an H2.0 hex key to tighten the spring fixing screw

[img https://wiki.snapmaker.com/u1/u1_extruder-unit_install-compression-spring-and-pressure-block.jpg]

[img https://wiki.snapmaker.com/u1/u1_extruder-unit_compression-spring-screw.jpg]

 Reinstall the extruder bearing holder and use an H2.0 hex key to tighten the 4 fixing screws

[img https://wiki.snapmaker.com/u1/u1_extruder-unit_extruder-bearing-housing.jpg]

 Mount the assembled extruder unit back onto the toolhead male mount in the orientation shown, and use H1.5 and H2.0 hex keys to tighten fixing screws 1, 2, 3, and 4 respectively

[img https://wiki.snapmaker.com/u1/u1_extruder-unit_assemble3.jpg]

## Step 2. Assemble the hotend cooling assembly

 Install the hotend cooling fan onto the fan base in the orientation shown (pay attention to the fan cable direction), and use an H1.5 hex key to tighten the 2 fixing screws

[img https://wiki.snapmaker.com/u1/u1_hotend-cooling-fan_assemble.jpg]

 Mount the hotend cooling assembly back onto the toolhead male mount, and use an H1.5 hex key to tighten the 3 fixing screws

[img https://wiki.snapmaker.com/u1/u1_hotend-cooling-assembly_install.jpg]

## Step 3. Assemble the hotend

 Install the ceramic heater

[img https://wiki.snapmaker.com/u1/u1_ceramic-heater_install.jpg]

 Install the thermistor (the probe tip needs to be bent 90°)

[img https://wiki.snapmaker.com/u1/u1_thermistor_bend.jpg]

[img https://wiki.snapmaker.com/u1/u1_thermistor_install.jpg]

 Install the ceramic heater retaining spring in place

[img https://wiki.snapmaker.com/u1/u1_ceramic-heater-clamp-spring_install.jpg]

 Install the cable holder, paying attention to orientation

[img https://wiki.snapmaker.com/u1/u1_cable-holder_install.jpg]

 Install the hotend silicone sock, ensuring the notched side faces the same direction as the cable holder

[img https://wiki.snapmaker.com/u1/u1_hotend-silicone-sock_install.jpg]

 Mount the hotend back onto the toolhead male mount, and use an H2.0 hex key to tighten the 2 fixing screws

[img https://wiki.snapmaker.com/u1/u1_hotend_screws.jpg]
