# Overview

## Location

 The docking Hall sensor board is located on the toolhead docking bracket, and can only be replaced after moving the toolhead away.

[img https://wiki.snapmaker.com/u1/u1_docking_hall_sensor_board_position.jpg]

## Difficulty and Time Estimate

 Difficulty ： ★ ☆☆☆☆ (easy)

 Estimated Time ：5 minutes

## Tools and Parts Required

 H1.5 hex key

 New docking Hall sensor board

# Procedure

## Step 1. Move the toolhead

 Select the toolhead (e.g., No.1) corresponding to the docking Hall sensor board to be replaced, then tap "Detach Toolhead" on the touchscreen.

[img https://wiki.snapmaker.com/u1/u1_detach_toolhead.png]

 Turn off the machine and unplug the power cable, then manually move the toolhead away from the docking Hall sensor board.

[img https://wiki.snapmaker.com/u1/u1_power_off_the_machine.png]

[img https://wiki.snapmaker.com/u1/u1_toolhead_move_away.png]

## Step 2. Remove the old docking Hall sensor board

 Use the H1.5 hex key to unscrew the two fixing screws.

[img https://wiki.snapmaker.com/u1/u1_docking_hall_sensor_board_screw.jpg]

 Press and hold the clip indicated by the arrow, then pull out the cable of the docking Hall sensor board.

[img https://wiki.snapmaker.com/u1/u1_docking_hall_sensor_board_remove_cable.jpg]

## Step 3. Install the new docking Hall sensor board

 Reconnect the cable to the new docking Hall sensor board.

[img https://wiki.snapmaker.com/u1/u1_docking_hall_sensor_board_cable.jpg]

 Use the H1.5 hex key to tighten the two fixing screws.

[img https://wiki.snapmaker.com/u1/u1_docking_hall_sensor_board_screw.jpg]
